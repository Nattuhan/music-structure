# 音源を根拠にしたクリック解析の修正（2026-09-09）

曲名・曲ID・固定時刻による分岐や補正ファイルは使用しない。最初に追加した曲専用レシピと、再解析でその固定値を引き継ぐ処理は削除した。

## 解析処理

`scripts/analyze_audio.py` はモデルの拍推定後に、元音源と拍列を `refine_timing_from_audio` に渡す。初回も再解析も同じ処理で、保存済みセッションや補正情報を参照しない。

- 冒頭は最初の32拍と小節頭が安定し、その前に同じ8分音符の位相を裏付けるアタックが複数ある場合だけ欠落拍を補う。無音や位相の合わない自由なイントロは補わない。
- 曲中は拍間隔が伸びた候補区間の前後3小節を比較する。前後のテンポが一致する場合も、それだけでは変更しない。
- 候補区間の音源から強いアタックを抽出し、前後のテンポに対応する8分音符上の位置を求める。すべての強いアタックの一致、複数の裏拍、複数の小節頭、区間両端の一致を要求する。アクセントの並びは固定しない。
- 根拠が揃った区間だけ、音源で確認した小節頭を結んで拍を復元する。単にテンポが違う区間や根拠のない区間は維持する。

判定は4/4の短い区間に限定する。実際のテンポ変更まで一律に平坦化しないため、根拠が不足するケースは変更しない。

CPUで元音源をモデルから再解析した最終検証でも、未補正出力は572拍・先頭1.83秒となり、問題区間の誤検知が再現した。共通処理の結果は580拍・先頭0.282秒となった。保存した未補正のモデル出力に最終版の共通処理を独立に再適用し、解析の入口から得た拍列・小節頭・補正記録と完全一致することを確認した。曲IDや保存済み補正は入力していない。
